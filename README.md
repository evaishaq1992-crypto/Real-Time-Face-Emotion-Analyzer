# Real-Time Facial Analysis & Emotion Detection System 👁️🎭

An advanced real-time computer vision pipeline built with Python, OpenCV, and MediaPipe to detect faces, track 3D facial landmarks (eyes, nose, lips), and classify facial expressions in real-time.

## ✨ Features
- 📌 **Facial Landmark Extraction:** Precise tracking for eyes, eyebrows, nose, and lips geometry.
- 🎭 **Emotion Analysis:** Dynamic facial expression classification (`happy`, `sad`, `angry`, `surprise`, `neutral`).
- ⚡ **Real-Time Video Stream:** High-FPS live webcam inference with smoothed temporal metrics.

## 🚀 Tech Stack
- Python 3.10+
- OpenCV
- MediaPipe / Custom Landmark Extractor
- NumPy & Dataclasses
